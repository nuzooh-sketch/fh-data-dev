How your data is stored

This database stores your personal data locally in this browser using Chrome's IndexedDB storage. Your Garage, Auction Data, Checklist, My Auctions, and related information remain on this computer unless you back them up or import a database.

Your data is not automatically saved to a separate backup file. Use Backup Database regularly to create a file you can keep somewhere safe.

If you clear this site's browser data, your locally stored database may be removed. Keeping regular backups is recommended.

Switching games preserves each game’s personal data

Your FH4, FH5, and FH6 personal data is stored separately inside one IndexedDB. Switching games only changes which game is active.

⚠ Reset Database

This will permanently delete the current game's local data.

This includes this game's Garage, Auction Data, My Auctions, Checklist, personal car edits, priorities, and other locally stored data.

FH4, FH5, and FH6 data are stored separately. Resetting the active game will not delete the other two games. The current game's static car database will be rebuilt automatically.
